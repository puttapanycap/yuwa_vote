## 1. ภาพรวมของระบบ

**YUWA Vote** เป็นระบบลงคะแนนเสียงออนไลน์ที่ออกแบบมาเพื่อใช้งานง่าย **ไม่ต้องสมัครสมาชิกหรือ Login** พร้อมฟีเจอร์ดังนี้:

- ✅ **ใช้งานได้ทันที** - ไม่ต้อง Login หรือสมัครสมาชิก
- ✅ **Session-Based Workspace** - แต่ละ Workspace มี Session Key เฉพาะ
- ✅ **แชร์ได้ง่าย** - Copy Link แล้วส่งให้คนอื่นเพื่อใช้งานร่วมกัน
- ✅ สร้างหัวข้อโหวตพร้อมตัวเลือกได้หลายรายการ
- ✅ กำหนดวันหมดอายุของการโหวต
- ✅ แสดงผลโหวตแบบ Real-time
- ✅ ป้องกันการโหวตซ้ำ (ตรวจสอบจาก IP และ Cookie)
- ✅ สร้าง QR Code สำหรับแชร์ลิงก์โหวต
- ✅ รองรับการแสดงผลแบบ Card และ List
- ✅ เลือกเปิด/ปิดการแสดงคะแนน

## 2. การติดตั้งระบบ

### 2.1 ความต้องการของระบบ

- **Web Server**: Apache หรือ Nginx
- **PHP**: เวอร์ชัน 7.4 ขึ้นไป
- **Database**: MySQL / MariaDB
- **Tools**: Laragon, XAMPP, WAMP หรือเซิร์ฟเวอร์ที่รองรับ PHP

### 2.2 ขั้นตอนการติดตั้ง

#### ขั้นตอนที่ 1: สร้างไฟล์ `.env`

สร้างไฟล์ `.env` ในโฟลเดอร์หลักของโปรเจกต์ โดยมีเนื้อหาดังนี้:

```env
VOTE_DB_HOST=localhost
VOTE_DB_USER=your_username
VOTE_DB_PASS=your_password
VOTE_DB_NAME=yuwa_vote

VOTE_WEB_URL=http://localhost/yuwa_vote/
```

| ตัวแปร | คำอธิบาย |
|--------|---------|
| `VOTE_DB_HOST` | ที่อยู่ของเซิร์ฟเวอร์ฐานข้อมูล (ส่วนมากคือ `localhost`) |
| `VOTE_DB_USER` | ชื่อผู้ใช้ฐานข้อมูล |
| `VOTE_DB_PASS` | รหัสผ่านฐานข้อมูล |
| `VOTE_DB_NAME` | ชื่อฐานข้อมูลที่ต้องการใช้ |
| `VOTE_WEB_URL` | URL ของเว็บไซต์ |

#### ขั้นตอนที่ 2: สร้างฐานข้อมูล

1. เปิดโปรแกรมจัดการฐานข้อมูล (เช่น phpMyAdmin)
2. สร้างฐานข้อมูลใหม่ชื่อ `yuwa_vote` (หรือชื่อที่ระบุใน `.env`)
3. Import ไฟล์ SQL จาก: `installer/yuwa-vote.sql`

#### ขั้นตอนที่ 3: รัน Migration Script (สำหรับ Session-Based System)

หากอัปเกรดจากระบบเดิม ให้รัน SQL Migration:

```sql
-- ไฟล์: installer/migration_session_key.sql
ALTER TABLE vote_topics 
ADD COLUMN session_key VARCHAR(64) NULL AFTER share_key;

CREATE INDEX idx_session_key ON vote_topics(session_key);
```

#### ขั้นตอนที่ 4: ทดสอบการติดตั้ง

เปิดเบราว์เซอร์และเข้าไปที่ URL ของเว็บไซต์ เช่น:
```
http://localhost/yuwa_vote/
```

ระบบจะสร้าง Session Key และ redirect ไปยัง URL ใหม่โดยอัตโนมัติ

## 3. การเริ่มต้นใช้งาน

### 3.1 เข้าสู่ระบบ (ไม่ต้อง Login!)

เพียงเปิดเว็บไซต์ ระบบจะสร้าง **Session Key** ให้อัตโนมัติ

URL จะเปลี่ยนเป็น:
```
http://localhost/yuwa_vote/?key=abc123def456...
```

> 💡 **สำคัญ**: บันทึก Link นี้ไว้! เพราะนี่คือ "กุญแจ" เข้าสู่ Workspace ของคุณ

### 3.2 หน้าหลัก (Dashboard)

หลังจากเข้าสู่ระบบ จะเห็น:

| ส่วน | คำอธิบาย |
|------|---------|
| **Hero Section** | แสดงโลโก้, Session Key และปุ่มจัดการ |
| **Copy Link** | ปุ่มสำหรับ Copy Link เพื่อแชร์ Workspace |
| **Stats Cards** | แสดงจำนวน Topics |
| **Topics Table** | รายการหัวข้อโหวตทั้งหมด |

### 3.3 Session Key คืออะไร?

**Session Key** เป็นรหัสเฉพาะของ Workspace ของคุณ:
- ใช้สำหรับเข้าถึง Topics ของคุณ
- แชร์ให้คนอื่นได้เพื่อจัดการ Topics ร่วมกัน
- ไม่มีวันหมดอายุ

## 4. การจัดการหัวข้อโหวต

### 4.1 การสร้างหัวข้อโหวตใหม่

#### ขั้นตอนการสร้าง:

1. คลิกปุ่ม **"+ เพิ่ม Topic"** ที่ Hero Section หรือในตาราง Topics
2. กรอกข้อมูลต่อไปนี้:

| ฟิลด์ | คำอธิบาย |
|-------|----------|
| **หัวข้อ (Topic Title)** | ชื่อหัวข้อที่ต้องการให้ลงคะแนน |
| **วันหมดอายุ (Expire DateTime)** | กำหนดวันและเวลาที่การโหวตจะสิ้นสุด |
| **ตัวเลือก (Choices)** | เพิ่มตัวเลือกสำหรับการโหวต (อย่างน้อย 1 รายการ) |
| **รูปแบบการโหวต (Vote Mode)** | เลือกได้ **1 ข้อ (เลือกได้อย่างเดียว)** หรือ **หลายข้อ (เลือกได้หลายข้อ)** |
| **จำนวนที่เลือกได้สูงสุด (Max Choices)** | กำหนดจำนวนตัวเลือกสูงสุดที่สามารถเลือกได้ (สำหรับโหมดหลายข้อ) |
| **รูปแบบการแสดงผล (Display Mode)** | เลือกระหว่าง Card หรือ List |
| **แสดงคะแนน (Show Score)** | เปิด/ปิด การแสดงจำนวนคะแนน |
| **เปิดสาธารณะ (Is Public)** | เปิด/ปิด การเข้าถึงแบบสาธารณะ |

3. คลิกปุ่ม **"เพิ่ม"** เพื่อบันทึก

#### การเพิ่มตัวเลือก:

- คลิกปุ่ม **"+ เพิ่มตัวเลือก"** เพื่อเพิ่มตัวเลือกใหม่
- กรอกชื่อตัวเลือกในช่องที่ปรากฏ
- สามารถลากเพื่อจัดเรียงลำดับตัวเลือกได้
- คลิกปุ่มถังขยะ 🗑️ เพื่อลบตัวเลือก

### 4.2 การแก้ไขหัวข้อโหวต

1. ในตาราง Topics คลิกปุ่ม ✏️ **แก้ไข** ในแถวของหัวข้อที่ต้องการ
2. แก้ไขข้อมูลตามต้องการ
3. คลิกปุ่ม **"บันทึก"** เพื่อบันทึกการเปลี่ยนแปลง

> 💡 **หมายเหตุ**: การแก้ไขตัวเลือกที่มีคะแนนโหวตแล้วจะไม่กระทบข้อมูลเดิม

### 4.3 การลบหัวข้อโหวต

1. ในตาราง Topics คลิกปุ่ม 🗑️ **ลบ** ในแถวของหัวข้อที่ต้องการ
2. ยืนยันการลบในกล่องข้อความที่ปรากฏ

> ⚠️ **คำเตือน**: การลบหัวข้อจะลบข้อมูลการโหวตทั้งหมดด้วย และไม่สามารถกู้คืนได้

## 5. การแชร์ Workspace

### 5.1 Copy Link

1. คลิกปุ่ม **"Copy Link"** ที่ Hero Section
2. ลิ้งค์จะถูก Copy ไปยัง Clipboard
3. ส่งลิ้งค์ให้คนอื่นเพื่อใช้งาน Workspace เดียวกัน

### 5.2 สร้าง Workspace ใหม่

หากต้องการเริ่มต้นใหม่:
1. คลิกปุ่ม **"Workspace ใหม่"**
2. ยืนยันการสร้าง
3. ระบบจะสร้าง Session Key ใหม่

> ⚠️ **หมายเหตุ**: หากไม่บันทึกลิ้งค์เดิมไว้ คุณจะไม่สามารถเข้าถึง Topics เดิมได้

### 5.3 ใครสามารถเข้าถึง Workspace ได้บ้าง?

- ทุกคนที่มี Link ของ Workspace
- ไม่มีระบบรหัสผ่านสำหรับ Workspace
- เหมาะสำหรับการใช้งานภายในทีมหรือองค์กร

## 6. การลงคะแนนเสียง

### 6.1 การเข้าถึงหน้าโหวต

ผู้ใช้ทั่วไปสามารถเข้าถึงหน้าโหวตได้ผ่าน:
- **ลิงก์ตรง**: `/vote.php?key=SHARE_KEY`
- **QR Code**: สแกน QR Code ที่สร้างจากระบบ

### 6.2 ขั้นตอนการลงคะแนน

1. เปิดลิงก์หน้าโหวต
2. อ่านหัวข้อและตัวเลือกที่แสดง
3. คลิกเลือกตัวเลือกที่ต้องการ (จะมีเครื่องหมายถูก ✓)
   - **โหมดเลือกได้อย่างเดียว**: เลือกได้เพียง 1 ตัวเลือก
   - **โหมดเลือกได้หลายข้อ**: เลือกได้หลายตัวเลือก (ตามที่กำหนดไว้)
4. คลิกปุ่ม **"ส่งผลโหวต"** เพื่อยืนยัน

### 6.3 สถานะต่างๆ ของหน้าโหวต

| สถานะ | คำอธิบาย |
|-------|----------|
| **พร้อมโหวต** | แสดงตัวเลือกและปุ่มลงคะแนน |
| **โหวตแล้ว** | แสดงข้อความ "ท่านลงคะแนนแล้ว" พร้อมเครื่องหมาย ✓ |
| **หมดเวลา** | แสดงข้อความ "หมดเวลาลงคะแนนแล้ว" พร้อมเครื่องหมาย ✗ |

### 6.4 การป้องกันการโหวตซ้ำ

ระบบป้องกันการโหวตซ้ำโดย:
- ✅ ตรวจสอบ IP Address ของผู้โหวต
- ✅ ตรวจสอบ Cookie Key ที่สร้างขึ้นอัตโนมัติ

## 7. การดูผลโหวตแบบ Real-time

### 7.1 หน้า Monitor

เข้าถึงหน้า Monitor ได้ 2 วิธี:

1. **จากหน้าหลัก**: คลิกปุ่ม 📊 **ดูผลโหวต** ในแถวของหัวข้อที่ต้องการ
2. **ลิงก์ตรง**: `/monitor.php?key=SHARE_KEY`

### 7.2 ฟีเจอร์หน้า Monitor

| ฟีเจอร์ | คำอธิบาย |
|---------|----------|
| **Auto Refresh** | อัปเดตข้อมูลอัตโนมัติทุกๆ 5 วินาที |
| **Play/Pause** | เริ่ม/หยุดการอัปเดตอัตโนมัติ |
| **Display Mode Badge** | แสดงโหมดการแสดงผลปัจจุบัน |
| **Score Badge** | แสดงสถานะการแสดง/ซ่อนคะแนน |

### 7.3 โหมดการแสดงผล

#### โหมด Card
- แสดงแต่ละตัวเลือกในรูปแบบ Card สวยงาม
- เหมาะสำหรับแสดงบนหน้าจอใหญ่
- มีอันดับ 1, 2, 3 พร้อมริบบิ้นสี

#### โหมด List
- แสดงในรูปแบบตารางเรียบง่าย
- เหมาะสำหรับข้อมูลจำนวนมาก
- ดูง่าย อ่านเร็ว

## 8. QR Code สำหรับแชร์ลิงก์

### 8.1 การสร้าง QR Code

1. ในตาราง Topics คลิกปุ่ม 📱 **QR Code** ในแถวของหัวข้อที่ต้องการ
2. ระบบจะแสดง QR Code ใน Modal

### 8.2 การใช้งาน QR Code

- **Vote QR Code**: สำหรับให้ผู้ใช้สแกนเพื่อเข้าหน้าลงคะแนน
- **Monitor QR Code**: สำหรับแสดงหน้าผลโหวตแบบ Real-time

### 8.3 การดาวน์โหลด QR Code

คลิกขวาที่รูป QR Code และเลือก "Save Image As..." เพื่อบันทึก

## 9. คำถามที่พบบ่อย (FAQ)

### ❓ ฉันลืมบันทึก Link ของ Workspace ทำอย่างไร?

น่าเสียดายที่คุณไม่สามารถกู้คืน Link ได้ ต้องสร้าง Workspace ใหม่

### ❓ ทำไมฉันโหวตไม่ได้?

**สาเหตุที่เป็นไปได้:**
1. คุณอาจโหวตไปแล้ว (ระบบตรวจสอบจาก IP หรือ Cookie)
2. หัวข้อนี้อาจหมดเวลาแล้ว

### ❓ ฉันเปลี่ยนใจได้ไหมหลังโหวตแล้ว?

ไม่ได้ ระบบไม่รองรับการเปลี่ยนแปลงคะแนนหลังจากโหวตแล้ว

### ❓ ทำไมคะแนนไม่แสดง?

ผู้สร้างหัวข้อโหวตอาจปิดการแสดงคะแนนไว้ ติดต่อผู้สร้างหัวข้อเพื่อเปิดใช้งาน

### ❓ ใครก็ได้ที่มี Link สามารถจัดการ Topics ได้หรือไม่?

ใช่ ทุกคนที่มี Workspace Link สามารถสร้าง แก้ไข และลบ Topics ได้

### ❓ ระบบรองรับมือถือไหม?

ใช่ ระบบออกแบบมาให้รองรับการใช้งานบนอุปกรณ์ทุกขนาดหน้าจอ (Responsive Design)
