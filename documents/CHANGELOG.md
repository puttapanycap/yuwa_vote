## [1.3.0] - 2026-02-03

### ✨ Added (เพิ่ม)
- เพิ่มระบบโหมดการโหวต (Vote Mode):
  - **โหมดเลือกได้อย่างเดียว (Single)**: เลือกได้เพียง 1 ตัวเลือก
  - **โหมดเลือกได้หลายข้อ (Multiple)**: เลือกได้หลายตัวเลือกตามที่กำหนด
- เพิ่มการกำหนดจำนวนตัวเลือกสูงสุด (Max Choices) สำหรับโหมดหลายข้อ
- เพิ่มคอลัมน์ `vote_mode` และ `max_choices` ในตาราง `vote_topics`

### 🔧 Changed (เปลี่ยนแปลง)
- จัดระเบียบ Modal จัดการ Topic เป็น Tabs:
  - Tab "ข้อข้อและเวลา" - ตั้งชื่อและเวลาหมดอายุ
  - Tab "ตัวเลือก" - จัดการตัวเลือกการโหวต
  - Tab "ตั้งค่า" - ตั้งค่าโหมดการแสดงผล, การโหวต และความเป็นส่วนตัว

### 🐛 Fixed (แก้ไข)
- แก้ไขปัญหา Clipboard API ไม่ทำงานใน HTTP (non-HTTPS) โดยเพิ่ม fallback method

## [1.1.0] - 2026-01-20

### ✨ Added (เพิ่ม)
- เพิ่มหน้า Monitor สำหรับดูผล Real-time
- เพิ่มการแสดงผลแบบ Card และ List
- เพิ่มปุ่ม Toggle แสดง/ซ่อนคะแนน
- เพิ่มปุ่ม Toggle เปิด/ปิดสาธารณะ
- เพิ่มนับถอยหลังบนหน้า Vote
- เพิ่ม Auto-refresh สำหรับหน้า Monitor
- เพิ่มปุ่ม Play/Pause สำหรับหยุดการ refresh

### 🔧 Changed (เปลี่ยนแปลง)

- ปรับปรุง UI หน้า Monitor ด้วย Gradient และ Animation
- เพิ่ม Ribbon สำหรับอันดับ 1, 2, 3

- แก้ไขปัญหาการแสดงผลบนมือถือ

## [1.0.0] - 2025-01-14

### ✨ Added (เพิ่ม)

#### ระบบผู้ใช้
- ระบบเข้าสู่ระบบ (Login)
- ระบบลงทะเบียน (Register)
- ระบบออกจากระบบ (Logout)
- บัญชีผู้ดูแลระบบเริ่มต้น (admin/1234)

#### ระบบจัดการหัวข้อ
- สร้างหัวข้อโหวตใหม่
- แก้ไขหัวข้อโหวต
- ลบหัวข้อโหวต
- กำหนดวันหมดอายุ
- เพิ่ม/ลบ/จัดเรียงตัวเลือก
- สร้าง QR Code สำหรับแชร์

#### ระบบลงคะแนน
- หน้าลงคะแนนสำหรับผู้ใช้ทั่วไป
- ป้องกันการโหวตซ้ำด้วย IP และ Cookie
- แสดงสถานะหมดเวลา
- แสดงสถานะโหวตแล้ว

#### ระบบฐานข้อมูล
- ตาราง vote_members (ผู้ใช้)
- ตาราง vote_topics (หัวข้อ)
- ตาราง vote_choices (ตัวเลือก)
- ตาราง vote_results (ผลโหวต)

#### โครงสร้างพื้นฐาน
- ใช้ Environment Variables (.env)
- Helper Functions (functions.php)
- Reusable Components (head, script, navbar, footer)
- Error Pages (403, 404, 500)
